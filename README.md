One word Grandma would text about AI: "Al" — she is sure he is a very nice young man who lives inside the computer, and she hopes he eats enough. The program writes that single word to `/output/entry.txt`, deterministically, with nothing else in the file.

## Run it

```sh
python3 main.py
```
